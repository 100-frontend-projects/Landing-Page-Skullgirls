Requisitos obligatorios
1. Barra de navegación

Debe contener:

Logo.
Nombre del producto.
Al menos 4 enlaces de navegación.
Un botón de acción (Ej. "Comprar", "Descargar", "Comenzar").

La barra debe permanecer siempre arriba de la página (investiga position: sticky 👀).

2. Hero Section

Debe incluir:

Un título llamativo.
Un subtítulo.
Un botón principal.
Un botón secundario.
Una imagen o ilustración del producto.

Debe ser la sección más llamativa de la página.

3. Sección de características

Muestra al menos 6 características del producto.

Cada una debe estar dentro de una tarjeta con:

Icono.
Título.
Descripción.

💡 Aquí quiero que uses CSS Grid para organizarlas.

4. Testimonios

Crea tres tarjetas con:

Foto.
Nombre.
Cargo.
Opinión.
5. Llamado a la acción (CTA)

Una sección donde invites al usuario a registrarse o comprar.

Debe destacar visualmente respecto al resto de la página.

6. Footer

Debe contener:

Logo.
Redes sociales.
Enlaces rápidos.
Copyright.
📱 Responsive

La página debe adaptarse correctamente a:

Escritorio.
Tablet.
Celular.

No quiero ver scroll horizontal.
